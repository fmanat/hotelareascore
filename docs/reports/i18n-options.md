# French version — options only (Bloc D)

2026-09-12. English launch remains the priority; no translated pages or flags.

A French version should wait until Phase 4 has an externally checked cohort,
indexing evidence and measurable French-language demand. It requires an owner
GO on scope and spend, not an automatic locale rollout. Avoid duplicating the
whole 15,700-profile build: that would exceed the current 20,000-file Pages
budget. A bounded set of useful French pages needs its own publication decisions.

## Planning cost, not a quote

- Small FR experiment: navigation, search/compare labels, methodology and a few
  selected city/profile templates, using the same structured facts and scores.
- Engineering and editorial QA assumption: 20–40 hours, plus owner/legal review.
  At an **illustrative internal rate of €50/hour**, this is €1,000–2,000 of work;
  it is not a supplier quote or an authorized expense. Owner-produced translation
  can have €0 cash cost but still consumes those hours. Obtain a real quote if
  outsourced; it would exceed the current setup budget and require approval.
- Software/translation API dependency: €0 proposed; deterministic templates and
  reviewed human translations. No per-view LLM. Small static experiment could
  remain within current hosting allowance after checking file/storage budgets.
- Recurring estimate: 1–3 hours/month for changed UI/fact templates and QA,
  plus any measured hosting costs. No promise that doubling all pages stays free.

## Prepare now, activate later

Preserve stable place IDs, original names, source Latin variants and independent
display names. Keep score calculation separate from labels and reason-code
wording. Existing dimension/reason keys can become translation keys later;
proper names must not be translated. Source English text is the reference.

Before any future FR release: define locale routes, record publication per
locale, translate and review templates/legal pages, then validate language tags,
canonicals, reciprocal hreflang and locale sitemap policy. No automatic bulk
translation or indexability; no locale routes/hreflang/sitemap changes in D.
